Calculator App
A responsive, interactive calculator web application for standard arithmetic calculations.

Features

Basic arithmetic operations (addition, subtraction, multiplication, division)

Clear (AC) and delete last entry functionality

Decimal number support

Dynamic display updates for inputs and results

Keyboard input support

Responsive design for desktop and mobile screens

Built With

HTML5

CSS3 (Flexbox / Grid)

Vanilla JavaScript

What I Learned

Structuring interactive UI elements with modern CSS

Advanced DOM manipulation and event listening (click and keyboard events)

Managing calculator state and edge cases (e.g., division by zero, consecutive operators, decimal limits)

Parsing and evaluating user input strings safely
